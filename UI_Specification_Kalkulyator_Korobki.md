## 1. Общие принципы дизайна

| Параметр | Значение |
|----------|----------|
| **Размер экрана** | Desktop 1440×900 (основной) |
| **Сетка** | 12 колонок, ширина 1200px, отступы 24px |
| **Шрифт** | Inter / Roboto |
| **Цветовая схема** | Сине-белая (#1a73e8, #ffffff) |
| **Скругления** | 8px для карточек, 12px для модальных окон |
| **Тени** | Карточки: `0 2px 8px rgba(0,0,0,0.08)` |
| **Отступы** | 24px между блоками, 16px внутри карточек |
